# Локальный запуск ABIevm и проверка StakeDAO

Проверенная версия Go: **1.27.2**. Откройте терминал в корне проекта — папке с `go.mod`.
При первом запуске Go скачает зависимости. Реальный RPC URL храните в переменной
окружения, не в исходниках. `.env` автоматически не читается.

## Проверка одного или трёх реальных пулов с GetBlock

Эта команда запускается отдельно от сервера и Swagger. Она читает регистрации
только в блоках **23225415–23225514** (100 блоков, уже проверенных вручную), затем
берёт до трёх действующих vault. Исторический `eth_getCode` не вызывается.
Все чтения состояния, включая расчёт наград, выполняются на одном свежем блоке.

В PowerShell задайте URL своего **Ethereum Mainnet** endpoint:

```powershell
$env:STAKEDAO_ETHEREUM_RPC_URL = "ВАШ_GETBLOCK_MAINNET_RPC_URL"
```

Если в этой PowerShell уже есть правильный `$rpc`, вместо копирования URL:

```powershell
$env:STAKEDAO_ETHEREUM_RPC_URL = $rpc
```

Сначала проверьте один пул:

```powershell
go run -mod=readonly ./cmd/stakedao-check -limit 1
```

Затем можно проверить до трёх и сохранить JSON для разбора:

```powershell
go run -mod=readonly ./cmd/stakedao-check -limit 3 | Set-Content -Encoding UTF8 stakedao-sample.json
```

В Linux/macOS:

```sh
export STAKEDAO_ETHEREUM_RPC_URL="ВАШ_GETBLOCK_MAINNET_RPC_URL"
go run -mod=readonly ./cmd/stakedao-check -limit 1
go run -mod=readonly ./cmd/stakedao-check -limit 3 > stakedao-sample.json
```

Команда делает не больше **5 RPC-запросов/с** и **300 RPC-попыток** за запуск.
Это ограничение запросов, не вычислительных единиц GetBlock: цена CU зависит от
метода. Лимит времени — 5 минут; прервать можно Ctrl+C. Автоматического перебора
других окон или повторной полной загрузки нет. Цены берутся из DeFiLlama и
кэшируются в памяти на время запуска; RPC-бюджет не включает HTTP-запросы цен.

В JSON смотрите `network`, `blockNumber`, `pools`, `errors`. В каждом пуле:
`name`, `vaultAddress`, `assetAmount`, `tvl`, `aprStatus`, `apr`, `rewards`.
`tvl` — USD, `apr` — годовая оценка наград в процентах. `apy` пока `null`.
Отсутствующая цена LP/asset не заменяется ценой компонента: TVL/APR могут быть
`null`, причина будет в `errors`. Диагностические сообщения идут в stderr,
JSON — в stdout. Наличие JSON не означает, что все значения доступны или уже
подтверждены независимым сравнением с UI StakeDAO.

В этом окне может оказаться меньше пулов, чем запрошено: отключённые vault и
регистрации, не соответствующие текущему Controller, пропускаются. Если подходящих
регистраций нет совсем, команда завершается ошибкой. Другой **известный** диапазон
можно указать через `-from` и `-to`, максимум 100 блоков включительно. Не нужно
сканировать все окна подряд на бесплатном тарифе. Набор выбирается по адресу gauge;
Curve V2 имеет поддержку основной награды, Balancer primary — пока нет.

Если произошла ошибка, пришлите её текст без ключа и URL. Полный приватный endpoint
команда в диагностике скрывает. GetBlock Mainnet уже подтвердил `eth_getLogs` на
100 блоков, но отказал в историческом `eth_getCode`; проверка ограниченной выборки
обходит именно этот исторический вызов. Live-результаты TVL/APR ещё нужно проверить.

## Запуск веб-сервера

```sh
go run -mod=readonly ./cmd
```

Echo слушает порт 8081. Проверить только запуск без RPC можно запросом
`GET /reservesStakedao/base`: ожидается HTTP 400, поддерживается только `ethereum`.

**Важно:** обычный `GET /reservesStakedao/ethereum` в Swagger по-прежнему сканирует
всю историю с диапазонами 2000 блоков и ищет блок создания через исторический
`eth_getCode`. Он пока несовместим с проверенным бесплатным GetBlock endpoint.
Для проверки 1–3 пулов используйте отдельную команду выше.

## Автоматические проверки

```sh
go test -mod=readonly -p 3 ./...
```

Тесты используют локальные HTTP/RPC-стенды, не бесплатные RPC.
Бизнес-модель и источники ABI: `internal/service/stakedao/README.md`.
Изменения публикуются в ветке `feat/stakedao-service`, без изменения `main`.
